# Nunjucks Syntax Plugin for Vim

A Vim plugin that provides syntax highlighting for Vento templates.

## Features

- Syntax highlighting for Nunjucks template tags (`{{`, `}}`, `{%`, `%}`, `{#`, `#}`)
- Support for Nunjucks keywords and operators
- Automatic filetype detection for `.vto` files
- Built on top of HTML syntax highlighting and Nunjucks plugin.

## Installation

### Using Vim-Plug

Add this line to your `.vimrc`:

```vim
Plug 'kuspoes/vim-vento'
```

Then run `:PlugInstall`

## Usage

The plugin will automatically detect and highlight `.vto` files. No additional configuration is needed.
